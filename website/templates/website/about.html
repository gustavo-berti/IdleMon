📝 Descrição do Projeto

O IdleMon é um sistema de gerenciamento de coleção de Pokémons desenvolvido como projeto acadêmico utilizando Django. O objetivo principal é simular um jogo idle onde os usuários podem adquirir ovos de Pokémon, chocá-los em diferentes espécies, organizá-los em boxes personalizadas e formar equipes que geram moedas automaticamente ao longo do tempo.

O sistema implementa conceitos fundamentais de desenvolvimento web com Django, incluindo:

  • Autenticação e Autorização: Sistema completo de registro, login e gerenciamento de contas de usuário
  • CRUD Completo: Operações de Create, Read, Update e Delete para todas as entidades principais
  • Relacionamentos Complexos: ManyToMany entre Espécies e Tipos, OneToOne entre User e PerfilTreinador, ForeignKeys para Boxes e Instâncias
  • Área Administrativa: Interface exclusiva para staff gerenciar Tipos de Pokémon e Ovos disponíveis
  • Sistema de Economia: Gestão de moedas virtuais, compra de boxes e ovos, geração passiva de recursos

🎭 Diagrama de Caso de Uso

O diagrama abaixo ilustra o principal ator do sistema (Treinador) e suas funcionalidades disponíveis.

Figura 1: Diagrama de Caso de Uso - Funcionalidades do Sistema

Funcionalidades do Treinador:
  • Manter Conta: Gerenciar informações de perfil e autenticação
  • Comprar Ovo: Adquirir ovos de Pokémon na loja
  • Chocar Ovo: Transformar ovos em Pokémons
  • Gerar Moedas: Obter rendimento através de Pokémons equipados
  • Gerenciar Boxes: Criar e organizar boxes de armazenamento
  • Organizar Pokémon: Mover e gerenciar Pokémons nas boxes
  • Consultar Pokédex: Visualizar informações dos Pokémons
  • Libertar Pokémon: Remover Pokémons da coleção

🗂️ Diagrama de Classes

O diagrama de classes representa a estrutura do banco de dados e os relacionamentos entre as entidades do sistema.

Figura 2: Diagrama de Classes - Estrutura de Dados do Sistema

Principais Classes e Relacionamentos:
👤 User

Atributos:
• username, email, password
Relacionamento:
• OneToOne com PerfilTreinador

💰 PerfilTreinador

Atributos:
• saldo_moedas (Decimal)
Relacionamentos:
• OneToOne com User
• OneToMany com Box e Ovo

⚡ TipoPokemon

Atributos:
• nome, valor_base_geracao
Relacionamentos:
• ManyToMany com Especie
• OneToMany com Ovo

🐉 Especie

Atributos:
• nome, estagio_evolucao
Método:
• calcular_media_tipo()
Relacionamentos:
• ManyToMany com TipoPokemon
• OneToMany com PokemonInstancia

📦 Box

Atributos:
• nome, slots_max (30)
Relacionamentos:
• ManyToOne com PerfilTreinador
• OneToMany com PokemonInstancia

⭐ PokemonInstancia

Atributos:
• apelido, data_nascimento
Método:
• gerar_lucro()
Relacionamentos:
• ManyToOne com Box e Especie

🥚 Ovo

Atributos:
• nome, preco
Método:
• chocar() → PokemonInstancia
Relacionamentos:
• ManyToOne com PerfilTreinador
• ManyToOne com TipoPokemon
• ManyToMany com Especie

💡 Observação Importante:
A média base de geração de um Pokémon é calculada pela fórmula: (Tipo1 + Tipo2) / 2, onde cada tipo possui um valor base de geração definido.
